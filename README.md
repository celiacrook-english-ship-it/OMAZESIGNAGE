# Omaze Office Signage

Live signage for OptiSigns TVs. Deployed via GitHub Pages.

## URL
After enabling Pages: `https://<yourusername>.github.io/<repo-name>/`

## To update
Replace `index.html` with a new version and commit. GitHub Pages redeploys in ~30 seconds.

## OptiSigns setup
Add a **Website** app in OptiSigns pointing at the Pages URL. Set refresh interval to 5 minutes.
